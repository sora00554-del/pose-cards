# Pose Cards

Windows向け模写練習アプリ「Pose Cards」の配布・更新ファイルを掲載しています。

## ダウンロード

[最新版のダウンロード・変更内容](https://github.com/sora00554-del/pose-cards/releases/latest)

Releasesに添付された `PoseCards-Windows-x64-バージョン番号.zip` を選び、展開して中のSetupを実行してください。Windows 10 / 11・64bitとMicrosoft Edge WebView2 Runtimeが必要です。

配布版に教材PDF・参考画像・既製のカード集は同梱していません。初回起動後に、自分で用意したPDF・JPG・PNGを追加できます。

## アプリの更新

1.3.7以降をSetupでインストールした場合、アプリ内の「アプリの更新」から最新版を確認・ダウンロードできます。更新前に描画内容・設定を保存し、記録・下書き・レイヤー・追加素材をバックアップしてから更新します。

1.3.6以前からは、一度新しいZIPのSetupを実行してください。旧版のアンインストールや保存データの削除は不要です。

## 毎日の記録

1.3.7以降は日本時間の午前4時に切り替わります。午前0〜3時台の練習は前日分です。保存済みの過去記録の日付は変更しません。

## 配布ファイルの確認

各リリースにSHA-256一覧を添付しています。第三者ソフトウェアの通知は配布ZIP内の `PoseCards-Third-Party-Notices.txt` を参照してください。
