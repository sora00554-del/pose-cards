# Pose Cards 1.3.6

PDF・JPG・PNGから練習用カードを追加し、見本の隣で描いて記録できるWindows向けアプリです。

- 画像・PDFの「検出して追加」「そのまま追加」とトリミング編集
- 重複なしのランダム表示、素材・カード別の対象選択
- 黒・赤・青のペン、最大120pxの消しゴム、投げ縄塗り
- 最大20枚のレイヤー、最大15回の1つ戻る・やり直し
- 格子の調整・ロック、見本との重ね合わせ、拡大・縮小
- 下書きの自動保存、練習履歴の再編集、目標・達成スタンプ
- A4 PDF・PNG ZIP書き出し、バックアップ・復元

## インストール・更新

`PoseCards-Windows-x64-1.3.6.zip` を展開し、中のSetupを実行してください。旧版のアンインストールや保存データの削除は不要です。

Windows 10 / 11・64bitとMicrosoft Edge WebView2 Runtimeが必要です。教材PDF・参考画像・既製のカード集は同梱していません。

現在の最新版は「Latest」のリリースから取得できます。
