# Pose Cards 1.3.10

- カードの表示順に「先頭から順番」を追加しました。「最初から」で先頭から練習できます。
- PNG書き出しを9件ずつ3×3に並べた横長1440×1020pxの画像にしました。
- まとめPNGのタイトルとファイル名に練習日と連番を付け、各絵の下に所要時間を表示します。
- A4 PDFにも所要時間を表示します。

## 更新方法

1.3.7以降をSetupでインストールしている方は、アプリの「アプリの更新」から更新できます。

初めて使う方は、PoseCards-Windows-x64-1.3.10.zipをダウンロードして展開し、PoseCards-Setup-1.3.10-Windows-x64.exeを実行してください。

Windows 10 / 11・64bit向けです。起動後に自分のPDF・JPG・PNGを追加できます。
