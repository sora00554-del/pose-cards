# Pose Cards 1.3.7

アプリ内更新と、毎日の記録の午前4時切り替えに対応しました。

- 「アプリの更新」で最新版・変更内容を確認し、ダウンロードから更新・再起動まで進められます。
- 更新前に描きかけ・設定を保存し、記録・下書き・レイヤー・追加素材をバックアップします。
- 更新ファイルのZIP・ハッシュ一覧・セットアップを照合します。
- 毎日の回数・目標・連続記録は日本時間の午前4時に切り替わります。午前0〜3時台の練習は前日分です。
- 記録画面を開いたままでも切り替え時に更新します。保存済みの過去記録の日付は変更しません。

## 1.3.6以前からの更新

今回だけZIPを展開してSetupを実行してください。アンインストールは不要です。記録・下書き・レイヤー・追加素材・設定は同じPC内の保存先を引き継ぎます。

1.3.7導入後は、新しい正式版の公開時にアプリ内から更新できます。

## 配布版について

教材PDF・参考画像・既製のカード集・個人の練習データは含みません。起動後に自分のPDF・JPG・PNGを追加できます。
