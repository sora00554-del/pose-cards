# Pose Cards 1.3.8

重ね合わせのプレビューへその場で描き込めるようになり、レイヤーの名前と色の操作を改善しました。

- **プレビューに描き込み**：答え合わせで元絵と重ねたまま、黒・赤・青のペンでメモや修正を追加できます。最上段のレイヤーへ同じ記録として自動保存します。消しゴム・太さ調整・1つ戻る・やり直しにも対応します。
- **レイヤー名を連番に**：最初は「レイヤー1」の1枚。「追加」で「レイヤー2」「レイヤー3」と続きます。保存済みの名前はそのまま復元します。
- **描いた線の色を一括変更**：選択中のレイヤー全体を黒・赤・青や好きな色へ変更できます。線の形・薄さとレイヤーの不透明度は保たれます。黒い絵を青い下書きへ変えて、別のレイヤーで描き直せます。色の変更は「Z」で取り消せます。

過去の記録への描き込みや修正では、元の日時・練習回数・練習時間を保持します。元のレイヤーや追加素材も引き継ぎます。

## 更新方法

1.3.7以降をSetupでインストールしている方は、アプリの「アプリの更新」から確認・ダウンロード・更新できます。起動時の確認でも更新を案内します。描いた内容の保存とバックアップ後に本体を更新します。

1.3.6以前の方は、`PoseCards-Windows-x64-1.3.8.zip` を展開し、`PoseCards-Setup-1.3.8-Windows-x64.exe` を実行してください。旧版のアンインストールや保存データの削除は不要です。

## 配布版について

Windows 10 / 11・64bit向けです。教材PDF・参考画像・既製のカード集・個人の練習データは含みません。起動後に自分のPDF・JPG・PNGを追加できます。
