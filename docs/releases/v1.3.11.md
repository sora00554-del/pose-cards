# Pose Cards 1.3.11

- 表示済みカードと表示順を保存し、出題範囲の切り替えや再起動後も残りのカードから続けられるようにしました。
- 素材ごとに対象枚数と残り枚数を表示します。
- 「残りをリセット」で選択中のカードを未出題に戻せます。
- 「出題範囲をリセット」で全素材・全カードを対象に戻せます。

初回更新時は、新しい進捗として残り枚数の記録を始めます。

## 更新方法

アプリの「アプリの更新」から更新してください。新規導入はPoseCards-Windows-x64-1.3.11.zipを展開し、Setupを実行してください。Windows 10 / 11・64bit向けです。
