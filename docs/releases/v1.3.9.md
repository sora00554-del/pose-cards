# Pose Cards 1.3.9

格子の濃さを調整し、最後に選んだ値を次回も使えるようになりました。

- **格子の濃さを調整**：「格子模写」の「格子の濃さ」で0〜100%に調整できます。初期値を薄めの30%にし、分割数を増やしても見本や描いた線を見やすくしました。見本とキャンバスの格子に同じ濃さを反映します。
- **前回の値を保持**：最後に選んだ濃さをPC内に保存します。新しい練習・下書き・過去の記録・アプリ再起動後も同じ値を使います。記録に古い濃さが保存されていても最後の値を優先します。
- **格子ロックとの併用**：位置をロックしたままでも濃さを調整できます。操作ハンドルは見やすさを維持し、濃さの設定もデータのバックアップに含めます。

保存済みの記録・画像・レイヤー・日時・練習回数・追加素材を引き継ぎます。格子の位置・分割数・ロック設定も保持します。

## 更新方法

1.3.7以降をSetupでインストールしている方は、アプリの「アプリの更新」から確認・ダウンロード・更新できます。起動時にも新しい版があることを案内します。描いた内容の保存とバックアップ後に本体を更新します。

1.3.6以前の方は、`PoseCards-Windows-x64-1.3.9.zip` を展開し、`PoseCards-Setup-1.3.9-Windows-x64.exe` を実行してください。旧版のアンインストールや保存データの削除は不要です。

## 配布版について

Windows 10 / 11・64bit向けです。教材PDF・参考画像・既製のカード集・個人の練習データは含みません。起動後に自分のPDF・JPG・PNGを追加できます。
