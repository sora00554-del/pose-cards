# Pose Cards 1.3.13

- 模写キャンバスの描画設定に「元絵を赤色で表示」を追加しました。チェックで赤色に切り替え、外すと元の色に戻せます。答え合わせの元絵にも反映します。
- PDFの1ページあたりの配置に18・27・45件を追加しました。18件以上はA4横向き、45件は横9列×縦5段です。初期値は45件です。
- PDFの日付・素材名・ページ情報・模写モード・所要時間を表示します。多数配置では文字と絵を小さくして収めます。

## 2026年11月9日 修正版

履歴のプログラムが読み込めなかった場合、履歴ボタンから再取得するよう修正しました。1.3.13を導入済みの方は、修正版ZIPを再ダウンロードしてSetupを実行してください。

## 更新方法

アプリの「アプリの更新」から更新できます。新規導入はPoseCards-Windows-x64-1.3.13.zipを展開し、Setupを実行してください。Windows 10 / 11・64bit向けです。
